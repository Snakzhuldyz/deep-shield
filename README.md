# DEEP SHIELD KZ

Цифрлық қауіпсіздік зертханасы. Дипфэйкті таны. Құқығыңды біл. Өзіңді қорға.

Оқушыларға арналған веб-қосымша: 5 қадам (ТОҚТА · ТЕКСЕР · САЛЫСТЫР · ҚОРҒА · ХАБАРЛА), ойын-сабақтар, бет-сканер, Face ID зертханасы, тест, цифрлық құқықтар. Жас бойынша 3 деңгей, көмекші – Сақбол.

Авторы: Ж. Зұлпыхарова, информатика пәні мұғалімі, С. Қожанов атындағы №9 жалпы білім беретін мектеп.

## Файлдар
- `index.html` – платформаның өзі
- `manifest.json` – телефонға қосымша етіп орнату баптауы
- `sw.js` – интернетсіз жұмыс істеуге арналған кэш
- `icon-192.png`, `icon-512.png` – қосымша белгішесі
